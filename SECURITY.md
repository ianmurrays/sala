# Security

Sala holds an Aula session (your MitID login) and shows children's data, so security reports matter.

## Reporting a vulnerability

Report it privately through GitHub: the repository's **Security** tab → **Report a vulnerability**. Don't open a public issue.

## Never post real Aula data

Not in issues, pull requests or discussions:

- screenshots of the app showing real names, photos or messages,
- captured traffic (`.cache/`, `aula-traffic.jsonl`) or Aula responses,
- tokens, cookies or anything from the Keychain.

Reproduce problems in [demo mode](README.md#demo-mode) instead: it runs on invented data.
